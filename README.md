PERSONAL LIBRARY & READING TRACKER 


## Features
- Add Books
- View All books
- Search books by genre
- Remove Books 
- Filter 
    - By Status :- 'To-read' , 'Reading' , 'Finished' 
    - By Genre
- Track Current Page 
- Finish date is recorded automatically.
- Statistics :
    - Total Books
    - Finished Books this month 
    - Favorite genre
- Logging -> logger


## Code Requirement
- Use OOPs
- Use Json
- Exception Handeling
- Proper Project Structure
- Use Proper Type Hints
- Not avoid PEP8 major violations
